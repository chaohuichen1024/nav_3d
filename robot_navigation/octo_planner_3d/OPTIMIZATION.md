# 三维导航优化说明

本轮优化将导航链从“地图每帧重规划 + 固定高度二维 DWA”调整为事件驱动全局规划和坡面感知局部控制。

## 已实现的阶段

1. 稳定性与安全
   - 地图更新默认不再触发全局重规划。
   - 卡住、路径失效时才从当前里程计位置重规划。
   - 相同路径不会重置局部路径索引。
   - 规划失败、里程计/点云超时会主动发布零速度。
   - 动态窗口使用里程计位置差分得到的实际速度，而不是上一条控制指令。

2. 实时地图
   - OctoMap 使用传感器原点进行射线插入，同时更新自由空间和占据端点。
   - 地图积分、完整地图发布和占据体素可视化分别限频。
   - 局部规划默认不再反序列化完整 OctoMap。

3. 坡面局部规划
   - 点云法向量用于区分可通行表面和障碍物。
   - 局部表面拟合为坡面，预测轨迹高度跟随坡面。
   - 路径最近点、前视距离和目标容差使用三维距离。
   - 上坡状态限制倒车和大角速度，并保持最低爬坡速度。

4. 全局可通行性
   - 禁止纯竖直体素移动和水平对角穿角。
   - 使用机器人半径、净空高度和最大可通行坡度检查空间。
   - 地图更新后验证尚未完成的路径；路径失效时从当前位置重规划。

5. 仿真接触
   - ODE quick solver 迭代次数由 10 提高到 50。
   - 限制过大的接触纠正速度，并为停车楼碰撞面指定摩擦系数。

## 参数入口

- `config/octomap_builder_params.yaml`：射线地图、传感器原点和发布频率。
- `config/global_planner_params.yaml`：机器人包络、重规划和路径验证。
- `config/local_planner_params.yaml`：DWA、坡面拟合、爬坡速度和进度看门狗。

`full_navigation.launch` 直接加载以上三个文件，避免 Launch 与 YAML 参数漂移。

## 验证

```bash
cd /home/yxc/robot_slam
catkin_make --pkg octo_planner_3d -j4
catkin_make run_tests_octo_planner_3d -j4
```

仿真重点观察：

- 每个新目标正常只发布一次全局路径；
- 日志中的 `Terrain mode` 在坡道上切换为 `UPHILL`；
- 正常跟踪阶段不再长期输出 `0.01/0.03 m/s`；
- 卡住 5 秒后发布 `/navigation/replan_request` 并停车；
- 动态物体离开后，对应 OctoMap 占据体素能被自由射线逐步清除。
